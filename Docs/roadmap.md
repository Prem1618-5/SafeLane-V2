# Roadmap: SafeLane v3 and Beyond

## Planned Features

- **Personal Access Tokens (PATs) Support**: Provide an officially supported flow to use GitHub PATs as an alternative to OAuth, fully validated and scoped, designed for internal/headless automation workflows.
- **Advanced Configuration Dashboard**: UI for repository-specific configurations, including custom release windows, holiday overrides, and specific rule exemptions.
- **Deep Incident Integration**: Deeper native integration with Datadog, PagerDuty, and other incident management systems to automatically pull recent postmortems for Incident Memory analysis.
- **Custom Security Rules Engine**: Allow organizations to define custom regex, AST, and semantic rules to run as part of the Deterministic Security Preflight.
- **Multi-SCM Support**: Expansion beyond GitHub to support GitLab and Bitbucket webhooks and API interactions.
